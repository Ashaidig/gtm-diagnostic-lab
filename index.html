Demo 6 - The foreign auto-tracker

Listeners

A script hardcoded into this page pushes form_submit for every form submission - events nobody configured in GTM. The toggle is your pause test.

Submit any form above with this on: a custom form_submit event appears carrying form_id and button text. Turn it off and resubmit: the ghost is gone - proof by elimination. Find the author: DevTools Network Search for form_submit_text; the only match is this page's own source.

Demo 7 - The embedded (iframe) form

Environments

The form below lives in a separate document. The parent page URL never changes, and parent GTM cannot see inside. Vendors solve this with bridge events.

Bridge on: submitting inside the frame produces a payment_complete event in the parent dataLayer. Bridge off: the widget works, parent GTM sees nothing at all.
